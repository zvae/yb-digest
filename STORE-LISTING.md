# YB Digest - YouTube & Bilibili

Unified Chrome / Edge MV3 extension, version 0.6.0.

Package: `dist/yb-digest-0.6.0.zip` (`npm run package`).

Supports YouTube native captions via Supadata and Bilibili official subtitles,
shared bilingual reading, full-video summaries, AI overviews, video Q&A and timestamped notes
in a tab-local page dialog. Closing the dialog cancels its unfinished AI requests.
YouTube captions require a Supadata key. AI features use the user's own provider.

Review `PRIVACY.md` before distributing. This merged build has not been
submitted to or approved by either browser store.
